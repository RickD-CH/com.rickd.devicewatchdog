Device Watchdog håller koll på alla dina Homey-enheter, så att du slipper. Den följer upp lågt batteri, enheter som slutat skicka ny data och enheter som Homey själv rapporterar som onåbara - allt på ett ställe, med förnuftiga standardvärden så att inget behöver konfigureras för att komma igång.

Fungerar med alla enheter på din Homey oavsett anslutningstyp - Zigbee, Z-Wave, Wi-Fi, Bluetooth eller 433 MHz - utan inställningar per märke. Varje enhet övervakas automatiskt; du kan utesluta enskilda enheter eller hela zoner med ett klick och vid behov finjustera batteri- och rapporteringströsklar per enhet. Ett manuellt nåbarhetstest, en löpande historiklogg, valfria aviseringar i Homeys tidslinje, en virtuell statusenhet för dina Insights och dashboards samt en dashboard-widget som visar exakt vilka enheter som behöver uppmärksamhet rundar av helheten, tillsammans med en komplett uppsättning Flow-kort för att bygga automationer kring det som hittas.
